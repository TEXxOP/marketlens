# Live end-of-day research snapshot

This folder is generated by running:

```bash
python run.py --source yahoo --output-dir research_runs/2026-09-08-live-eod
```

`run_metadata.json` records the exact time, date range, instruments, strategy
configuration, transaction costs, leverage limit, source caveat, and output
metrics. The CSV files are the matching inputs and results for this snapshot.

This is a documented paper-simulation output using delayed public data. It is
not investment advice and it does not imply that the strategy will work in the
future.
