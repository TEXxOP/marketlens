# Versioned research runs

This directory stores selected reproducible output bundles used to document the
project. Each bundle includes the raw end-of-day price inputs, positions,
portfolio returns, event-study output, walk-forward output, and metadata with
the exact date range, costs, limits, source caveat, and configuration.

The committed runs are research snapshots. They are not forward-looking claims,
investment advice, or evidence of a deployable trading strategy.
